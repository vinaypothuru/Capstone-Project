# IIT- Madras Capstone-Project

Predictive Analytics for Project Delays and Budget Overruns

An end-to-end data analytics and machine learning project focused on analyzing historical EPC (Engineering, Procurement, and Construction) project data to identify key factors contributing to project delays and budget overruns. The project explores multiple dimensions, including labor utilization, contractor performance, procurement activities, safety incidents, financial metrics, environmental conditions, and project characteristics.

The objective is to uncover hidden patterns, identify critical risk indicators, predict potential project delays and cost escalations, and provide actionable insights through data-driven analysis. The ultimate goal is to enable proactive project risk management, improve schedule adherence, optimize resource utilization, control project costs, and enhance overall project profitability.

Key Focus Areas:
- Exploratory Data Analysis (EDA) and data preprocessing.
- Identification of factors influencing project delays and cost overruns.
- Feature engineering and selection.
- Predictive modeling using machine learning techniques.
- Project risk assessment and performance analysis.
- Data-driven recommendations for improving project execution.
